Session 7: Capstone and Incident Response

Two halves. First, chain the whole town for a high score, quietly. Then sit on the other side of the table and work the incident.

7.1 The capstone run

One run, timed from your first arm. The scoring rewards chaining distinct techniques on one subsystem, so plan the order. A worked example of the shape, not a script:

  1. Recon by name. Pull the zone transfer and the reverse zone. Read the directory. Now you have the org chart, and you have spent almost no heat doing it.
  2. Get a residential foothold. The SOHO router on its default login, its capture page, the reused rail credential. You are into OT without touching a single loud web target.
  3. Stage the rail derail but do not fire it. Read the console key. Wait for the loading cycle.
  4. Work Main Street for the chain bonus while the town is calm. The quiet techniques first (IDOR, the exposed backup, the .git leak), then the mediums.
  5. Time the loud moves to the events. Not while the news crew is filming your subsystem. Not with an inspector on site. The parade is the one exception: if you are going to hijack a signal, the parade is when it counts.
  6. The bank last, or whenever you have accepted that Alert Level 2 is coming and you have already used every default credential you were going to need.

Compare your run to a loud one: run the same techniques again without regard for the events or the meter, and watch the speed multiplier collapse and the stealth bonus disappear. The delta is the lesson.

7.2 The tabletop

Now you are the SOC. Reset the town, have someone else run a chain against it, and work the response from the artefacts you actually have:

QuestionWhere the answer lives
When did it start, and from where?the gateway JSON access log (gw-logs volume): tool user-agents, 4xx bursts, path spray
What did the Alert meter see, and when?alert.blue_actions in the state snapshot; pkt/alert/level on the bus
Which subsystems are off-golden right now?the map, and GET /api/state
Was OT reached directly or through a pivot?status.sh containment probe; which web target went loud first
Did the blue team's automatic responses help or just annoy the attacker?compare a run where Level 2 fired mid-chain against one where it did not

Then the recovery: ./reset.sh per subsystem, verify golden against docs/verification.md Section C, and write the two-paragraph "what we would change" that every real incident ends with. For Packet River the answer is almost always in Session 6's four patterns. Saying which one, and naming the specific default or missing control, is the exercise.
