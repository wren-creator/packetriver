Session 6: Now Close Every Hole

Goal for this session: run the same attacks against the same range with one flag flipped, and watch them fail. This is ./start.sh --segmented, which folds docker-compose.segmented.yml on top of the base stack. A training environment that only shows you the break is half a lesson.

6.2 The pattern

Look down that list. There is no patch in it. Every fix is one of four things: authenticate the channel (the broker ACL, the SNMPv3 move, the bearer token), stop trusting a claim you did not verify (pin the JWT algorithm, require the AS/400 password), encrypt what was in the clear (TLS the Diner portal and the crew portal), or segment so the reachable thing is not the sensitive thing (the Modbus re-assert, WAN-admin off, the OT network drop at Alert Level 4).

That is the whole defensive syllabus for this class of target. The boring attacks have boring fixes. The hard part in the real world is never knowing the fix; it is inventory, ownership, and the political will to change a default on a system somebody is afraid to touch.

6.3 What is still open, and why

The segmented build's detection story is the gateway log tailer, the broker ACLs, and the PLC golden re-assert. A dedicated inline IDS (Suricata watching a span port) is on the roadmap and not shipped, because a container on a Docker bridge only sees its own traffic and broadcast; a real sensor needs a mirror interface or a router container, which is a topology change. The book calls that out rather than shipping theatre.
