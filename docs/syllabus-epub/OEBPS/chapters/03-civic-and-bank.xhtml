Session 3: City Hall, the Money, and the Green Screens

Goal for this session: drain the town's money three different ways, and see why a modern web front door and a fifty-year-old terminal host end up at the same place. This is the civic tier, the payment gateway, First Packet Bank & Trust, and the two mainframes behind them.

3.2 The bank

First Packet Bank & Trust is a Node/Express app on 127.0.0.1:8100: a login portal, a customer dashboard, a JSON accounts API, and a staff-only transfer form. Two ways in:

  • The token check honours alg:none. Re-issue your own customer token with an elevated role and no signature, and the staff dashboard opens and prints the Fed wire settlement token in the clear. This is CVE-2015-9235 and a decade of copies since; MITRE T1550.001. Fix: pin the algorithm, reject none, verify the signature, and do not render a settlement token into HTML.
  • The accounts API has no ownership check. Walk the account ids and one memo carries a municipal reconciliation token. OWASP API1:2023 again. Fix: enforce ownership on every account read; keep secrets out of free-text fields.

Draining the bank fires bank_drain: carded, balance zero, ATM drained, and the alarm panel, which is wired to the industrial power feeder, drops on the map.

3.3 The AS/400 behind City Hall

A real TN5250 host on 127.0.0.1:8992: a SIGNON panel, a menu tree, and Interactive SQL. Three stacked IBM i misconfigurations, all real: a blank password is accepted for any profile, the way unhardened low-QSECURITY boxes behaved; a powerful profile still has its shipped default password; and the payroll library is left readable to the public, so any signed-on profile can read it from STRSQL. Drive it with the bundled as400_5250.py, or hand-drive from the browser terminal. Submitting fires the same cityhall_payroll effect as the web LFI path: the money is gone whichever way you got in.

Fix: set QSECURITY to 40 or above, require passwords, rotate the shipped defaults, restrict powerful profiles' device access, and pull *PUBLIC on the payroll library down to *EXCLUDE with an authorization list. Default and blank IBM i credentials are a standing finding in every AS/400 security review, and *PUBLIC *ALL on application libraries is the single most common IBM i exposure.

3.4 The IBM z16 behind the bank

Core banking on a z/OS LPAR: a real TN3270E host with a RACF logon panel, TSO READY, and a RACF command family (LISTUSER, RLIST, SETROPTS LIST). Two paths:

  • z16_racf. A default admin was never revoked; it still holds SPECIAL and OPERATIONS and still logs on with its shipped password. A banking transfer-approval profile is world-readable and in WARNING mode, so a failed access check is logged but allowed, the control is fail-open, and someone parked a reconciliation key in that profile's readable metadata. A never-revoked default admin is a standing pen-test finding on z/OS; WARNING mode left in place for years is a classic audit hit.
  • z16_apf. LISTAPF flags a library that is APF-authorised and also world-writable. An APF library you can write to is an APF library you can subvert: link a routine in, CALL it, and you are running in supervisor state, key 0, with total control of the LPAR. "World-writable APF library" is one of the highest-severity findings a z/OS review can produce, and it is not rare. It is a straight line from UPDATE on a dataset to key 0.

Both fire bank_drain. Fix for the RACF path: revoke the default admin or strip its authority and rotate it, take the profile out of WARNING, set UACC(NONE) with an access list, SETROPTS PROTECTALL(FAILURES), and never put secrets in profile metadata. Fix for the APF path: no writable APF libraries, tight authority on the volumes that hold them, program control on APF modules, and audit every APF-list change.

3.5 What you should notice

Five different technologies, one outcome. The web app trusts a token's own claim about how it was signed. The API trusts a number in the URL. The AS/400 trusts a blank password. The z16 trusts a default admin nobody removed, and a dataset permission nobody checked. The money does not care which door you came through.
