Packet River - CTF answers
==========================

Flags are minted fresh every time `scoring` (re)starts - there is no static
answer list. To see the current run's flags:

    docker compose exec scoring python -c \
      'import sqlite3; [print(f"{t}\t{f}") for t,f in \
       sqlite3.connect("/data/scoring.db").execute("SELECT technique_id,flag FROM flags")]'

The step-by-step for every technique (sign-on, payload, exact flag location) is
in ../answer-key.md. The instructor scenario notes with MITRE mappings and
real-world parallels are in ../../docs/scenarios.md.

check-flags.sh in this directory smoke-tests the whole mint -> plant -> submit
-> score loop for all 26 techniques without re-running the exploits. Run it
after `./start.sh` and after any change to scoring / flags / effects:

    ./instructor/ctf/check-flags.sh

Expected: "24 ok, 0 failed". It fires every town effect as a side effect, so
follow it with `./reset.sh -y`.
